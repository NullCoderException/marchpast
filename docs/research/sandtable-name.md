# Is "Sandtable" free to use as the product's name?

*Research note for issue #125 (part of the v0.3 map, #121). Every check was run on 2026-09-07. Nothing was registered, bought or signed up for. Not legal advice.*

## Verdict: rename

**"Sandtable" is not free.** Two facts decide it, both found in the USPTO register on 2026-09-07:

1. **Sandtable, Inc.** (Delaware corporation, Roswell GA; site `sandtable.co`, "AI-enabled military planning, simulation, collaboration and rehearsal") filed USPTO application **99925941** for the standard-character mark **SANDTABLE** on **2026-07-07**, in classes **9 and 42**, claiming use since 2025-05-22. The goods are "downloadable computer software for simulation and modeling to assist in ... mission planning ... simulation of geospatial environments ... terrain development ... tactical training, mission rehearsal", and the class 42 services are the same as SaaS. That is the same word, in the same classes, for software that animates armies over terrain. A qualifier ("Sandtable Battles") would not separate us from it.
2. **SIMTABLE** (Simtable LLC, Santa Fe; owns `sandtable.org`) was **registered** on 2026-04-21 (reg. 8220332, classes 9, 41, 42) for "computer simulation software for modeling Earth systems ... landscape" and "software ... for interactive simulation and animation". A second live, near-identical mark in the same field.

Neither mark is registered in the EU or UK (TMview's EUIPO and UK IPO datasets return nothing for "sandtable" or "sand table"), so a UK-hosted hobby project is not going to be sued tomorrow. But the product is published on GitHub Pages to a US audience, the name could never be registered by us, a store listing under the name would be one takedown request away, and a third US company (Virtual Sandtable LLC, live mark VTAK) already trades on the same word for military simulation software. The name also has no free `.com`, `.app`, `.io` or `.org`, and no free npm name. Keeping it means building a brand we can never own on a word three other simulation-software companies already use.

**Three candidates checked the same way, all clear at exact match in USPTO and TMview, on npm, and on both `.app` and `.dev`:**

| | Fit | npm | `.app` / `.dev` / `.com` | App stores | Trademark |
|---|---|---|---|---|---|
| **Marchpast** | A parade of troops filing past; the battle marches past you. Neutral, one word, easy to say. | free | free / free / free | none | Zero hits anywhere (USPTO, TMview). Ordinary noun, so weakly distinctive but unowned. |
| **Battleplot** | Says exactly what the app is: battles, plotted. Most discoverable. | free | free / free / free | none; results are war-strategy games | Zero exact hits. Enters a field of live PLOT marks in classes 9/42 (construction and workflow software), so a later registration could draw a citation; a hobby project would not. |
| **Plotting Room** (`plottingroom`) | The WWII naval plotting room: a table, counters, arrows. Closest to the original image. | free | free / free / **taken** (registered 2026-05-10, GoDaddy) | none | Zero exact hits. Shares "ROOM" with a live class 9/42 collaboration-software mark. Two words. |

Recommendation for the brand ticket (#135): **Marchpast** if the priority is a clean name we can own outright; **Battleplot** if the priority is being found. Both have every sensible domain free at list price (`.app` USD 8.75 first year / 14.93 renewal, `.dev` 8.75 / 12.87, `.com` 11.08 / 11.08 at Porkbun, 2026-09-07). The domain task (#136) should wait for #135's pick and then register `.app` and `.dev` for it; `.com` too if it is free at the time, since it is the same price as a renewal.

Dropped along the way: **Fieldglass** (SAP Fieldglass, a major class 9/42 mark), **Warplot** (`warplot.com` held since 2010; otherwise clean), **Orrery**, **Cartouche** and **Vedette** (taken on npm).

## Method and sources

- npm: `https://registry.npmjs.org/<name>` (public registry metadata: publish times, maintainers, readme).
- Domains: RDAP direct from each registry as listed above, via `https://rdap.org/domain/<name>` for the bootstrap redirect; `nslookup` for `.co`, `.xyz`, `.gg`; `curl -I` for what each registered name serves. Prices: Porkbun public pricing API.
- App Store: iTunes Search API. Google Play: store search page fetched and read; AppBrain for the Good Tree Soft listing (the Play detail page refuses non-browser fetches).
- Trademarks: USPTO Trademark Search and TSDR, TMview, WIPO Global Brand Database, as described in that section; driven through Chrome by a background agent on 2026-09-07.
- Companies: [WPP acquires data science firm Sandtable](https://www.wpp.com/en/news/2020/03/wpp-acquires-data-science-firm-sandtable) (2020-03-05); [sandtable.co](https://sandtable.co/) (Sandtable, Inc.); [simtable.com](https://simtable.com/); [Sand Motion on the App Store](https://apps.apple.com/us/app/sand-motion/id6754465708).
- GitHub: `gh search repos sandtable`; `gh api repos/anthropics/sandtable` (404).
